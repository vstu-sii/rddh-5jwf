# Прототип UI

Кликабельный прототип ключевых экранов на демо-данных. Сгенерирован агентом (Claude Code) по PRD, метрикам quality и гипотезе команды, лежит в репозитории как код. Нужен, чтобы проверять use cases, а не для визуального дизайна.

Без сборки и зависимостей: чистые HTML, CSS и JS.

```bash
# вариант 1 — открыть index.html в браузере
# вариант 2 — в составе dev-окружения
docker compose -f compose.dev.yml up -d
# приложение сотрудника: http://localhost:3000/employee.html
# кабинет бухгалтера:    http://localhost:3001/backoffice.html
```
